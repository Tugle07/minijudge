Cho dãy $n$ số nguyên **không âm** $a_1, a_2, \dots, a_n$ và số $K$. Đếm số **đoạn con liên tiếp** $[l, r]$ ($1 \le l \le r \le n$) có tổng $a_l + a_{l+1} + \dots + a_r = K$.

### Input
- Dòng 1: $n, K$ ($1 \le n \le 2 \cdot 10^5$, $0 \le K \le 10^{15}$).
- Dòng 2: $n$ số nguyên $a_i$ ($0 \le a_i \le 10^9$).

### Output
In ra số đoạn con thỏa mãn.
