# Sắp xếp các từ theo thứ tự từ điển

## Đề bài
Cho xâu ký tự $S$ gồm nhiều từ phân cách nhau bởi dấu cách. Hãy sắp xếp các từ trong xâu theo thứ tự từ điển tăng dần và giảm dần.

## Định dạng đầu vào (Input Format)
Dòng duy nhất chứa xâu ký tự $S$.

## Ràng buộc (Constraints)
$1 \le |S| \le 10000$

## Định dạng đầu ra (Output Format)
Dòng 1 in các từ theo thứ tự từ điển tăng dần.
Dòng 2 in các từ theo thứ tự từ điển giảm dần.

## Ví dụ
### Đầu vào
```
python java c cplusplus algorithm
```

### Đầu ra
```
algorithm c cplusplus java python
python java cplusplus c algorithm
```
