# Phân tích thừa số nguyên tố

## Đề bài
Hãy phân tích một số nguyên dương $N$ thành tích các thừa số nguyên tố.

## Định dạng đầu vào (Input Format)
Số nguyên dương $N$.

## Ràng buộc (Constraints)
1 <= N <= 10^16

## Định dạng đầu ra (Output Format)
In ra phân tích thừa số nguyên tố dạng $p^e$.

## Ví dụ
### Đầu vào
```
28
```

### Đầu ra
```
2^2 * 7^1
```
