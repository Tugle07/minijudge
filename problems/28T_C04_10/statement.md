# Tính tổng 5

## Đề bài
Tính tổng S(n) = 1/1 + 1/2 + 1/3 + ... + 1/n bằng đệ quy.

## Định dạng đầu vào (Input Format)
Số nguyên dương n.

## Ràng buộc (Constraints)
1 <= n <= 1000;

## Định dạng đầu ra (Output Format)
In ra S(n) lấy 3 số sau dấu phẩy.

## Ví dụ
### Đầu vào
```
4
```

### Đầu ra
```
2.0833
```
