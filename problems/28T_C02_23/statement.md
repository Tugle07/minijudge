# Vẽ hình 3

## Đề bài
Vẽ tam giác vuông cân kích thước $N$ bằng các dấu `*`.

## Định dạng đầu vào (Input Format)
Số nguyên dương $N$.

## Ràng buộc (Constraints)
1 <= N <= 50

## Định dạng đầu ra (Output Format)
In ra tam giác vuông cân.

## Ví dụ
### Đầu vào
```
3
```

### Đầu ra
```
*
**
***
```
