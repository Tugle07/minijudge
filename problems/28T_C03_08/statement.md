# Số chính phương 3

## Đề bài
Đếm số lượng số chính phương trong đoạn $[a, b]$.

## Định dạng đầu vào (Input Format)
Hai số nguyên dương $a, b$.

## Ràng buộc (Constraints)
1 <= a <= b <= 10^18

## Định dạng đầu ra (Output Format)
In ra số lượng số chính phương.

## Ví dụ
### Đầu vào
```
1 50
```

### Đầu ra
```
7
```
