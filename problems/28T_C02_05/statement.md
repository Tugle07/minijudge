# Tổng nghịch đảo 2

## Đề bài
Tính tổng $S(n) = 1/2 + 1/4 + 1/6 + ... + 1/(2n)$.

## Định dạng đầu vào (Input Format)
Số nguyên dương $n$.

## Ràng buộc (Constraints)
1 <= n <= 10^5

## Định dạng đầu ra (Output Format)
In ra kết quả lấy 4 chữ số thập phân.

## Ví dụ
### Đầu vào
```
2
```

### Đầu ra
```
0.7500
```
