# Tính giai thừa

## Đề bài
Tính giai thừa của số nguyên dương $n$: $n! = 1 * 2 * ... * n$.

## Định dạng đầu vào (Input Format)
Số nguyên dương $n$.

## Ràng buộc (Constraints)
0 <= n <= 15

## Định dạng đầu ra (Output Format)
In ra giá trị $n!$.

## Ví dụ
### Đầu vào
```
5
```

### Đầu ra
```
120
```
