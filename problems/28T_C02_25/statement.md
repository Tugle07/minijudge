# Thương giai thừa

## Đề bài
Cho số nguyên $N$. Hãy tính tổng $S = 1/1! + 1/2! + ... + 1/N!$.

## Định dạng đầu vào (Input Format)
Số nguyên dương $N$.

## Ràng buộc (Constraints)
1 <= N <= 15

## Định dạng đầu ra (Output Format)
In kết quả lấy 4 chữ số thập phân.

## Ví dụ
### Đầu vào
```
3
```

### Đầu ra
```
1.6667
```
