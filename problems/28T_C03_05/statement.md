# Tổng ước số

## Đề bài
Tính tổng tất cả các ước số của số nguyên dương $N$.

## Định dạng đầu vào (Input Format)
Số nguyên dương $N$.

## Ràng buộc (Constraints)
1 <= N <= 10^12

## Định dạng đầu ra (Output Format)
In ra tổng các ước của $N$.

## Ví dụ
### Đầu vào
```
12
```

### Đầu ra
```
28
```
