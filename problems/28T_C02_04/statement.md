# Tổng nghịch đảo

## Đề bài
Tính tổng $S(n) = 1 + 1/2 + 1/3 + ... + 1/n$.

## Định dạng đầu vào (Input Format)
Số nguyên dương $n$.

## Ràng buộc (Constraints)
1 <= n <= 10^5

## Định dạng đầu ra (Output Format)
In ra kết quả lấy độ chính xác 3 chữ số sau dấu phẩy.

## Ví dụ
### Đầu vào
```
2
```

### Đầu ra
```
1.500
```
