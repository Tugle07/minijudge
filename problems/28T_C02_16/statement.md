# Đếm chữ số của n

## Đề bài
Đếm số lượng chữ số của số nguyên không âm $n$.

## Định dạng đầu vào (Input Format)
Số nguyên không âm $n$.

## Ràng buộc (Constraints)
0 <= n <= 10^18

## Định dạng đầu ra (Output Format)
In ra số lượng chữ số của $n$.

## Ví dụ
### Đầu vào
```
12345
```

### Đầu ra
```
5
```
