# Kiểm tra nhiều test case

## Đề bài
Cho số lượng trường hợp $T$. Với mỗi số $N$, kiểm tra xem $N$ là chẵn hay lẻ.

## Định dạng đầu vào (Input Format)
Dòng 1 chứa $T$. $T$ dòng sau chứa số nguyên $N$.

## Ràng buộc (Constraints)
1 <= T <= 1000; 0 <= N <= 1000

## Định dạng đầu ra (Output Format)
Mỗi test in EVEN hoặc ODD trên một dòng.

## Ví dụ
### Đầu vào
```
2
4
7
```

### Đầu ra
```
EVEN
ODD
```
