# Số chính phương 4

## Đề bài
Tìm số chính phương nhỏ nhất lớn hơn hoặc bằng $N$.

## Định dạng đầu vào (Input Format)
Số nguyên dương $N$.

## Ràng buộc (Constraints)
1 <= N <= 10^12

## Định dạng đầu ra (Output Format)
In ra số chính phương nhỏ nhất $\ge N$.

## Ví dụ
### Đầu vào
```
20
```

### Đầu ra
```
25
```
