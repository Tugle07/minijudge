# Giải phương trình

## Đề bài
Cho 3 số nguyên $a, b, n$. Kiểm tra xem phương trình $ax + by = n$ có nghiệm nguyên không âm $(x, y)$ hay không.

## Định dạng đầu vào (Input Format)
3 số nguyên $a, b, n$.

## Ràng buộc (Constraints)
1 <= a, b <= 100; 1 <= n <= 10^5

## Định dạng đầu ra (Output Format)
In YES nếu có nghiệm, ngược lại in NO.

## Ví dụ
### Đầu vào
```
2 3 7
```

### Đầu ra
```
YES
```
